# Component Load Testing

Директория для тестирования компонентов под нагрузкой с использованием проекта `project_for_component_test.zip`.

## Назначение

Тестирование компонентов на диаграмме под нагрузкой для проверки:
- Время выполнения каждого компонента на диаграмме
- Промежуток времени между выполнением компонентов
- Производительность компонентов при параллельных запросах
- Анализ метрик выполнения компонентов

## Структура

```
component_load/
├── README.md                    # Документация
├── locustfile.py               # Основной файл для нагрузочного тестирования компонентов
├── test_cases/                 # Описание тестовых кейсов
│   └── component_metrics.md    # Описание метрик и кейсов
├── scripts/                    # Вспомогательные скрипты
│   └── analyze_component_timing.py  # Анализ времени выполнения компонентов
└── reports/                    # Отчеты по тестированию
```

## Проект для тестирования

Проект `project_for_component_test.zip` находится в корне репозитория и используется для тестирования компонентов.

## Метрики

### Основные метрики компонентов:
1. **Время выполнения компонента** - длительность выполнения отдельного компонента
2. **Интервал между компонентами** - время между завершением одного компонента и началом следующего
3. **Общее время выполнения диаграммы** - суммарное время выполнения всех компонентов
4. **Параллельное выполнение** - анализ выполнения компонентов при параллельных запросах
